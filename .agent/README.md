# writerD · AI 接手配置目录

> 本目录是给**下一位 AI 构建者**的技能与方法配置。读完 `S:\writerD\交接报告.md`（唯一入口）后，再读本目录，即可无缝接手。

## 目录内容

| 文件 | 内容 |
|---|---|
| `SKILLS.md` | 构建本项目用到的 agent skill 清单 + 用法 + 触发场景 + 安装/恢复方法 |
| `METHODS.md` | 上一轮 AI 实际使用的工作方法（实证流程、复刻纪律、踩坑规避），带本轮真实案例 |
| `skills/inkwell-dev.md` | **姊妹项目 Inkwell 的工作手册（最重要的一份）**——同一委托方、同一对标物 OpenWrite v2.0.1、更成熟的复刻工程，其纪律与坑 90% 直接适用于 writerD |

## 30 秒上手

1. 先读 `../交接报告.md` —— 现状、红线、下一步、自查清单。
2. 再读 `skills/inkwell-dev.md` —— 同一产品的成熟版本怎么做，照它的纪律来。
3. 拿不准的事：查 `../docs/CONTRACT.md`（接口真源）→ 查 `../docs/spec/`（逐字规格）→ 查 `../reference/`（逆向证据）→ 都不够用再翻本目录的方法论。
4. 环境坑：`../交接报告.md` §10 + `skills/inkwell-dev.md` §7，两处的坑都是实测踩出来的。

## 红线速记（违反即前功尽弃）

1. 不创新、不臆造——有实证照做，无实证标 `[待实测]`。
2. 证据先行——没有当场实测输出的「完成」不算完成。
3. 格式优先 / 写前快照 / 路径分级三授权根。
4. 密钥不入库（DeepSeek key 只填运行时，绝不进 git）。
5. 绝不复制对标产品提示词原文/图标/素材。
6. **绝不用 PowerShell 写中文源码**（编码陷阱，不可逆，已毁过文件）。
