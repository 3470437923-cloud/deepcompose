# ADR-003 配置键数更正与规格文档落地

- 状态：已采纳
- 日期：2026-09-28
- 证据：`docs/spec/PREFS.md`（552 行，由 `docs/spec/_extract/gen_prefs.py` 生成，可重跑）

## 事实更正

`docs/CONTRACT.md` §3.3 原记 `shared_preferences.json`「实测 442 键」。复核结论：**43 键**。

- `json.load` 实测：8293 字节、单行 JSON、43 个键，全部带 `flutter.` 前缀（43/43）。
- 「442」无法从只读证据复现；`WIN_app.so.strings.txt`（96176 行）中仅 1 条以 `flutter.` 开头的串。
- CONTRACT §3.3 列出的 30 个键名**逐个命中真实 JSON**，故只有数字错误，键名清单可信。

## 决定

1. `CONTRACT.md` §3.3 改为「实测 43 键」，并加更正说明指向本 ADR 与 `docs/spec/PREFS.md`。
2. 新增 `docs/spec/` 作为**比 CONTRACT 更细的实现规格层**：CONTRACT 保留「唯一接口真源」地位（逐字文案与协议），
   `docs/spec/*.md` 承载**可实现的明细表**（全键清单、工具 schema 全文等），两者冲突时以**原始证据文件的偏移**为准并回写 CONTRACT。
3. 本产品配置沿用同一套键名（去掉 `flutter.` 前缀），存储位置按 CONTRACT §3.2 改名：
   `%APPDATA%\com.writerd\writerD\shared_preferences.json`。

## 复刻要点（来自 PREFS 提取，均为实测）

- **AI 接入 11 键**：`llm_base_url`（不含 `/v1`）、`api_key`、`model`、`temperature`(0.8)、`context_limit`(1000000)、
  `use_anthropic_format`(false)、`saved_providers`、`system_prompt`、`reserved_output_tokens`(16000)、
  `auto_clear_context`(true)、`official_api_key`。
- `saved_providers` 元素字段为驼峰：`name`/`baseUrl`/`apiKey`/`model`/`useAnthropicFormat`；无 `id`/`isActive`。
- `novel_projects` **不是 JSON**，是 `\n` 分隔的绝对路径。
- `skill_list` 元素字段：`id`/`name`/`description`/`directoryPath`/`isBuiltIn`/`marketplaceSkillId`/`marketplaceVersion`。
- `webdav_config`：`url`/`username`/`password`/`remotePath`/`lastSyncTime`；
  `webdav_sync_meta`：`version`/`lastUploadTime`/`scopeTimestamps{projects,skills,sessions,memos}`。
- **面板尺寸全为 float**：`panel_session_width=220.0`、`panel_chat_width=523.0`、`panel_directory_width=200.0`、
  `panel_memo_width=320.0`、`chat_font_size=15.0`、`editor_font_size=15.0`；可见性三键 `panel_show_*`。
- `custom_accent_color=4286343935` = `0xAARRGGBB` = `#7C6AFF`（与 CONTRACT §1 三方验证一致）。
- **切除**：`vip_*` 8 键 + `device_id`（共 9）。
- 另有 62 个「二进制中存在、本机无值」的偏好键候选，见 `PREFS.md` §8；其中尾随 `r` 的形态（`official_api_keyr`
  等）是 AOT 字符串粘连噪声，**不得当作键名**。
