# ADR-002 品牌标识替换（logo 与产品名）

- 状态：已采纳
- 日期：2026-09-28
- 来源：用户提供的新产品 logo `S:\writerD\IMG_8741.PNG`（1024×1024，带透明通道）

## 决定

1. **应用图标**：由 `tauri icon` 从用户 logo 生成全套 `src-tauri/icons/`
   （`icon.ico` / `icon.png` / `32x32` / `64x64` / `128x128` / `128x128@2x` + Windows Store 系列 + iOS/Android 系列），
   覆盖原先的 Tauri 默认图标。`tauri.conf.json` 的 `bundle.icon` 引用项全部为已生成文件。
2. **界面品牌标**：`convert_mock.py` 新增 `brand()` 后处理，把 mock 的 `.brand-mark > svg`（OpenWrite 紫色渐变占位标）
   替换为 `src/assets/logo.png`，产品名 `OpenWrite` → `writerD`。该后处理在生成器里，重新生成不会丢失。
3. **样式**：`.app-shell .brand-mark{background:none}` + `img{width/height:100%;object-fit:contain}`
   写在 `base.css`（本项目自有文件），`screens.css` 保持「由 mock 机械转换、禁止手改」的纯净状态。

## 理由

mock 的紫色渐变与 `OpenWrite` 字样属于对标产品的品牌资产；本产品名为 writerD，且用户已提供新标识。
除品牌标识与产品名外，**未改动任何尺寸、色值、结构与文案**。

## 复验证据

- `tauri icon` 退出码 0，`src-tauri/icons/icon.ico` 47.7 KB，mtime 2026-09-28 00:42。
- `python tools/convert_mock.py` 后 `screens.css` 逐字节未变（`screens.css 未被改动: True`），
  两个 tsx 的 `brand-mark` 为 `<img src={logo} alt="" />`、`brand-name` 为 `writerD`。
- `tsc --noEmit` 退出码 0；`vite build` 产出 `dist/assets/logo-*.png` 892 KB。
