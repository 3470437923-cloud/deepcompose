# DeepCompose 1.1.1

修复技能加载、单文件搜索和继续写作候选选择，保持现有作品目录与数据格式兼容。

## 修复

- 修复macOS/POSIX技能扫描和加载使用错误路径分隔符，导致已声明技能无法加载。技能结果补充实际目录，支持名称与时间戳目录不同的情况。
- 修复指定单个Markdown/TXT文件搜索时错误返回零命中；缺失路径明确报错，保留行号、命中上限和授权规则。
- 修复继续写作比较章号解析对象导致选中旧候选。优先状态文档明确最新指针，无有效指针时按章号回退，保留用户历史稿。
- 修复合法链接授权根的搜索兼容，后代链接仍不展开。
- macOS应用包使用完整ad-hoc签名，绑定Info.plist与资源；修复原有测试未定义变量。

## 下载与兼容

本版提供 **macOS Apple Silicon（arm64，macOS 14+）** 安装镜像与SHA-256。Windows/Linux源码包含共用修复，本轮未在这两个平台重建及原生验收，不提供冒充新版本的旧二进制。Windows历史下载保留在[v1.1.0](https://github.com/3470437923-cloud/deepcompose/releases/tag/v1.1.0)。

macOS包为本机ad-hoc签名，**未经Developer ID签名与Apple公证**，下载后可能需要在系统设置的隐私与安全性中确认打开。作品保持本地Markdown格式；调用AI时所需内容发送到用户配置的服务，请备份作品与应用数据。
