# DeepCompose 1.1.2

本版继续修复工具安全回执、追踪表格式兼容、文本检索和二进制读取边界，兼容既有作品目录与磁盘契约。

## 修复

- `delete_lines` 返回被删内容预览、剩余行数、写后哈希和写前快照位置。
- 区分读文件与列目录的缺失错误；缺少 `operation` 时提示可用操作。
- 追踪表按模板验证：既有缺字段条目允许编辑并告警，新违规会明确指出条目；角色状态和废弃设定不再被要求添加不存在的状态字段。
- 搜索支持 JSON/JSONL、日志和常见文本文件，报告排除或不可读文件；限制返回片段大小且确保命中词保留。
- replace 失败给出实际近似行和行号，成功给出命中与替换统计，不进行模糊替换。
- file_read 限制返回字符数，提供续读位置和跨行分隔符。
- Rust 文件桥与测试桥拒绝 ZIP、PDF、图片、可执行文件等按文本读取，保留 UTF-8/UTF-16/GBK 文本兼容；普通以 MZ 开头的文本不再误判。

## 验证

- TypeScript 类型检查通过。
- Vitest：56 个测试文件，747 通过，9 跳过。
