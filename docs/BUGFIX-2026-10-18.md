## 发布与桌面边界

macOS包使用完整bundle ad-hoc签名，codesign --verify --deep --strict通过；首次包仅有linker签名而失败，修复为bundle.macOS.signingIdentity为“-”。ad-hoc不等于Developer ID/Apple公证，spctl拒绝不应说成Gatekeeper认可。安装镜像需通过hdiutil verify，并附SHA-256。

已安装修复版并核对程序坞、进程路径和发布包一致性。发布v1.1.1须从对应源码提交重建，以新的版本和哈希为准，旧1.1.0本机哈希不作为本次Release依据。

发行版WKWebView内完整Agent工具回合尚未端到端自动重放：当前osascript辅助访问遭拒。真实FS测试与Rust单测覆盖业务及文件原语，不能冒充原生界面端到端验证。Windows/Linux本轮未提供重建安装包。

## 2026-10-19 增补验收（v1.1.2）

- GB-01：delete_lines 现在返回删除内容预览（带截断标记）、剩余行数、写后 SHA-256 和快照位置/会话信息；快照仍在写盘前落地。
- GB-02/GB-09：追踪校验按模板处理。角色状态与废弃设定不再凭空要求状态字段；伏笔统计标题允许模板解释后缀；既有缺字段条目可编辑但告警，新条目、删状态或改坏条目会拒绝并指出实际条目。拒绝写入不会改文件，CRLF 保留。
- GB-03/GB-11：按 read/list 区分 File not found 与 Directory not found；缺 operation 错误提示可用操作。
- GB-04：递归与单文件搜索支持 json/jsonl、log 等常见文本和日志；排除/不可读文件出现在 skipped_files，未再静默当作零命中。
