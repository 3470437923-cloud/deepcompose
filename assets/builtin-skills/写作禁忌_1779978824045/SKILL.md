# 写作禁忌（写作前必须完整阅读，禁止蒸馏精简阅读，禁止不遵循规范，不遵循规范的内容不允许生成）
> 雷区速查 · 每次写作前必须逐条核对
---
## 一、句式硬性禁止
1. **破折号（——）**：全文禁用。用句号/逗号/冒号/自然衔接替代
2. **"不是…，而是…"句式**：直接陈述，不先否定再肯定
3. **过度"但…"转折**：能直接转折就不用"但"
4. **多段重复修饰同一情绪**：一次足够
5. **解释性文字**：让行动和细节自己说话，不替读者总结人物动机
6. **直白心理独白**：情绪通过动作、环境细节、微表情传递

## 三、写法禁止
| 禁止项 | 说明 |
|---|---|
| 时间标签流水账 | 禁用"第X天""第二天清晨""三天后"等驱动场景；用事件驱动、概括性表述、细节累积变化替代 |
| 同段视角切换 | 禁止在同一段落内切换视角，必须用场景分隔符 `××××` |
| 对话过多 | 以行动推进关系，能用行动推进的不用对话说明 |
| 大量/生疏比喻 | 以日常事物为喻体，避免华丽古风辞藻 |
| 日历翻页叙事 | 让读者感受时间流淌，而非看到时间刻度 |
| **日常动作过度分解** | 切葱、倒水、洗碗等日常动作一笔带过，不要逐步分解每个细节 |
| **环境细节重复堆砌** | 同一场景内光线、绿萝等环境元素只出现一次，不要反复描写 |
| **情感表达重复** | 耳朵红、脸红等生理反应同一场景只用一次，不要反复出现 |
| **对话填充** | 无信息量、无情绪推进的对话删除，如"那我明天早起""要放葱吗""放" |
