# 小说去AI味：根因分诊

AI味不是词表问题，是生成习惯问题。同一个词在真人笔下成立、在AI笔下露馅，区别在根因：**告诉代替呈现、均匀代替节奏、解释代替信任、堆砌代替选择**。检测信号只用来定位根因；找到根因做最小修正，不做无差别清词。

## 使用纪律

1. **改最少，效果最大**：能改一个词不改一句，能删一句不重写一段。
2. **只改「怎么说」，不改「说什么」**：剧情、人设、事实、伏笔、钩子一概不动。
3. **不整段删除**：单段多处信号 → 逐句修；删除会破坏情节连贯 → 降AI重写而非删。单次删除量不超过原文 15%。
4. **拿不准标 [建议人工审核]**，不硬改。
5. 本书 `小说资料/06-写作规则.md`（含个人文风节）的要求**优先于**本清单；两者冲突时按本书规则执行。
6. 用户的稿子：只出报告 + question 确认后才动笔（writerD 铁律）。AI 自己的初稿做逐段修改时可直接改。

## 检测清单（按根因分组）

### A. 告诉代替呈现

| 信号 | 常见表现 | 根因与最小修正 |
|---|---|---|
| 情绪直陈 | 他很紧张 / 感到一丝失落 / 心中充满空虚 | 情绪标签先于身体与选择。换成可见反应或删（上下文已够）：手在抖、把手机放回口袋 |
| 情绪标签补丁 | 动作描写后面又补一句「他很难过」 | 不信任读者。删补丁，留动作 |
| 解释性总结 | 替读者归纳人物动机、意义、主题 | 删。让行动和细节自己说话 |
| 心理独白过长 | 大段内心分析、括号式内心标注 | 压到一两句，或转成感知与动作 |
| 散文式收尾 | 章尾抒情总结、哲理金句、「他知道…」「这一刻…」 | 换成具体动作、未完成事项或感官细节收束 |

### B. 均匀代替节奏

| 信号 | 常见表现 | 根因与最小修正 |
|---|---|---|
| 段落等长 | 每段都是 3—5 行，工整均匀 | 真人段落 1—3 句为主，重音处才放长。拆匀：叙事主力段 2—3 句，强调用独句段（连续不超过 5 个），重音段 4—6 句 |
| 一句一动作流水账 | 他起身。他走到窗边。他拉开窗帘。 | 机械分解。合并有因果的动作串，删无信息步骤 |
| 日常动作过度分解 | 切葱、倒水、洗碗逐步写 | 过渡动作一笔带过；笔墨留给转折与冲突场面 |
| 三连排比/对称句 | 连续三句以上同构句式 | 保留一个最有力的，其余改直陈或删 |
| 节奏全程平扁 | 无起伏无重音，或全程高密度 | 找本章重音场面放大，过渡压缩 |

### C. 语言惯性（AI 高频件）

| 信号 | 常见表现 | 根因与最小修正 |
|---|---|---|
| 否定转折框架 | 「不是A，而是B」「没有A，没有B」「并不A，却B」 | AI 最爱的强调模板。直接陈述 B；确需否定就自然口语化 |
| 破折号成癖 | 每章十几处「——」 | 多数可用句号/逗号/冒号替代；真人偶用，不成癖 |
| 模糊量词装饰 | 一丝、一抹、些许、几分、隐约 | 删，或换具体细节 |
| 万能动词补丁 | 缓缓、微微、轻轻、淡淡、深吸一口气 | 高频出现即删；确需节奏时保留一处 |
| 表情套路 | 眼中闪过、嘴角勾起、眉头微皱、瞳孔微缩 | 换该人物此刻真实会做的动作 |
| 书面腔连接 | 于是、随即、然而、与此同时、由此可见、不禁、不由得 | 用动作衔接或直接删 |
| 「只见/就在这时」 | 说书人腔 | 删，直接写事件 |
| 机械对话标签 | 每句都「XX说道/问道」+ 副词（冷冷地说） | 六成为上无标签，用动作替代；副词删，语气进台词本身 |
| 分析性名词 | 机制、结构、逻辑、体系出现在叙事里 | 换日常说法 |
| 华丽违和比喻 | 如寒冰般、仿佛XX降临 | 喻体换日常事物；比喻一章不超过 3 个 |

### D. 对话失真

| 信号 | 常见表现 | 根因与最小修正 |
|---|---|---|
| 讲解问答 | 人物互相复述双方都知道的设定 | 假问答。删，或改成只有新信息的一角 |
| 对话填充 | 无信息无情绪的寒暄（「那我明天早起」「要放葱吗」「放」除非刻画关系） | 删；对话要么推情节要么露人物 |
| 人人同腔 | 所有角色说话一样书面、一样完整 | 按身份、关系、压力区分语气；允许省略、打断、答非所问 |
| 动机自白 | 角色把自己的打算解释给对手听 | 删；动机进选择 |

### E. 内容与状态失真

| 信号 | 常见表现 | 根因与最小修正 |
|---|---|---|
| 时间标签流水账 | 「第二天清晨」「三天后」「第X天」驱动场景 | 日历翻页。用事件驱动转场，让读者感受时间流淌而非看刻度 |
| 环境细节重复 | 同一场景光线/陈设反复描写 | 一个场景一次，选最有信息量的那次 |
| 生理反应复读 | 同一场景耳朵红/脸红/手抖出现多次 | 同场景同反应只用一次 |
| 感官单一 | 全程只有视觉 | 关键场景补触/听/嗅/身体感各一处即可，不堆满（感官是锚点不是清单：具体不适比「他很累」有效十倍） |
| 状态无故复原 | 伤势、持物、情绪上一章还在，下一章消失 | 一致性问题，报 novel-writer 回流核对追踪表 |
| 视角越界 | 写出聚焦人物看不到/听不到的信息；同段切视角 | 收回视角内；切视角必须换场景分段 |
| 上帝预告 | 「他不知道的是…」「这是最后一面」 | 删，命运感留给事件本身 |

## 工作流

**Pass 1 扫描**：通读全文，按 A—E 组标记信号位置（段落号 + 短引 ≤20 字）。只标有依据的，不为凑数硬找。
**Pass 2 分诊**：每个信号问一句「根因是什么」——同根因合并处理（如三处情绪直陈都源于不信任读者，统一策略）。区分：必须改（露馅）/ 可改可不改（风格选择）/ 不该改（作者刻意为之）。
**Pass 3 最小修正**：按分诊结果改。每处改动可回溯到根因。
**Pass 4 复读**：从修改点前一段读到后一段，确认承接、语气、节奏没有新伤；读出声测试——像人说话即通过。

## 输出格式（报告制）

```
## 去AI味报告
- 总体判断：轻 / 中 / 重（一句话依据，不打分）
- 信号统计：A组N处 / B组N处 / …

| 位置 | 信号 | 根因 | 处理 | 修改（前→后，短引） |
|---|---|---|---|---|

- 未处理项与理由：…
- [建议人工审核]：…
```

用户只要检测时不给修改稿；要润色时报告后附修正文本（或按 writerD 流程写入候选新版本）。

## 与其他技能的协同

- **novel-writer 逐段修改**：初稿→候选的修改遍直接按本清单检测修正（自己的稿子可直接改）。
- **novel-writer 回流审稿**：对用户手改稿只做检测报告，动稿必须 question。
- **novel-structure-quality-coordinator**：结构/逻辑问题归它，表达/AI味问题归本技能；同一遍发现两类问题时分开列。
