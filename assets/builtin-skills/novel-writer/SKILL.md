# 小说写作助手

当用户要求以下操作时使用此skill：
- 写小说、写新章节、续写章节
- 同步文档、更新维护文档
- 初始化小说项目、创建新小说

## 工作流程

### Step 1: 读取维护文档
按以下顺序读取项目中的维护文档：
1. `小说资料/人物库.md` - 所有角色设定
2. `小说资料/世界观.md` - 设定细节
3. `小说资料/章节摘要.md` - 之前所有章节的情节点汇总

### Step 2: 读取上下文资料
1. 检查 `章节内容/` 目录，读取最近更新的五个章节文件
2. 如果目录为空或章节不足5章，则读取所有已有章节

### Step 3: 创作新章节
根据以下信息创作：
- 章节摘要中的情节点
- 人物库中的角色信息
- 世界观设定
- 最近五章的情节走向
- 用户的具体要求

**重要：每章字数要求最少2000字（中文），确保内容充实、情节流畅完整**

### Step 4: 输出格式
**⚠️必须先将完整章节内容输出到回复中给用户观看，然后再询问是否保存，禁止直接用file_write工具保存文件**

输出格式：
```
# 第X章 标题

[章节正文，至少2000字]
```

### Step 5: 征求保存确认（必须执行）

**重要：在保存任何文件之前，必须先使用 question 工具询问用户是否保存！**

调用 question 工具示例：
```
工具名: question
参数:
{
  "questions": [{
    "question": "章节已创作完成，是否保存到文件？",
    "header": "保存确认",
    "options": [
      {"label": "保存", "description": "保存章节内容到文件"},
      {"label": "我先想想", "description": "暂时不保存，再考虑一下"}
    ]
  }]
}
```

**只有当用户选择"保存"后，才能调用 file_write 工具保存文件！**

### Step 6: 保存章节
用户确认保存后：
1. 将章节正文保存到 `章节内容/第X章.md`

### Step 7: 征求维护文档更新确认
使用 question 工具询问用户是否更新维护文档。

### Step 8: 更新维护文档
用户确认后：
1. 更新人物库：新角色追加，状态更新
2. 更新世界观：新设定追加
3. 更新章节摘要：新摘要追加
4. **格式优先**：如果用户修改过维护文档的格式（增减字段、调整结构），则以用户当前文件中的格式为准，不要恢复为模板格式

## 同步模式
当用户说"同步文档"、"更新维护文档"时：
1. 读取最新章节内容
2. 重新生成本章摘要（简短几句话概括本章核心情节）
3. 使用 question 工具征求确认后更新
4. 更新人物库和世界观
5. **格式优先**：同步更新时保持用户当前文件中的格式，不要恢复为模板格式

## 初始化模式
当用户说"初始化小说项目"、"创建新小说"、"创建新书"时：
1. 使用 `create_project` 工具创建项目（传入用户指定的书名）
2. 使用 question 工具询问初始设定（题材、风格等）
3. 根据用户回答，仅写入以下固定文件（参考模板格式）：
   - `小说资料/人物库.md`
   - `小说资料/世界观.md`
   - `小说资料/章节摘要.md`
4. 提示项目初始化完成

⚠️ **初始化时严禁创建以下文件之外的任何文件**：不要创建大纲文件、设定集、额外资料等。后续如需添加，需用户明确要求。

## 重要提醒
- **任何写入操作前必须先用 question 工具确认**
- **创作章节后必须先将内容展示给用户，然后再询问是否保存**
- 不要在没有用户确认的情况下自动保存文件
- **写入文件时不要在回复中重复内容**：直接调用 file_write 工具，内容只放在工具参数中，回复只需简要说明操作（如"正在写入第一章..."）
- **尽量在一次回复中同时调用多个 file_write**：例如初始化项目时，应该一次性调用所有 file_write 写入世界观、人物库、章节摘要等文件，而不是分多次回复逐个写入
