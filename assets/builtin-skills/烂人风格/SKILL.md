# 写作风格

> 伪男强救赎文、双男主纯爱文，内核BE、互相折磨。
> 表面男频强强爽文（节奏、张力、钩子），内里纯爱悲剧（情感、细节、留白）。
> **核心风格词：冷、短、平、硬切。**

冷峻、克制的现实主义叙事。以冷静笔触描写边缘人物生存状态。大量短句、重复、留白。通过细节和环境烘托情绪，避免直接抒情。叙事像镜头缓慢推进，聚焦人物内心与环境的微妙互动。极少使用形容词，靠动词和名词构建画面。

---

## 一、表面的冷感，内里的纯爱

**冷感外壳**：句子短但不碎，逗号呼吸、句号停顿。独句成段是常态，连续不超过5个。场景硬切，不做过渡。人物有锋芒，对话极少，每句出刀。不钻角色内心——心理活动只在关键时刻给一次，半句就够。

**纯爱内核**：大量安静的、不需要语言的段落。情感不喊出来，压进动作和细节。留白比说明多——最重的感情不写出来。唯一的"热"来自两个烂人之间偶尔漏出来的真实。

---

## 二、句号与节奏

关联紧密的判断/动作/感受用逗号串，句号只用在语义断点上。

**正确：**
> 墙很冷，是那种渗进骨头里的冷。水泥墙漆了一层浅灰，漆面已经磨损，露出底下的粗糙。

**错误：**
> 墙很冷。是那种渗进骨头里的冷。水泥墙漆了一层浅灰。漆面已经磨损。露出底下的粗糙。

**段落节奏：**
- 独句段：强调。连续最多5个。
- 2-3句段：叙事主力。
- 4-6句段：重音（回忆、冲突、深度情感）。
- 禁止连续超过8个独句段。

短句传达紧张、压迫或麻木。重复特定句式或词汇（"没有"、"画圈"）建立节奏，强化核心意象。

---

## 三、感官锚点（强制）

每个场景至少嵌入3种感官信息。没有感官的冷感叙事是空壳。

| 感官 | 要求 |
|------|------|
| 视觉 | 光的质量、颜色、距离——不写"灯亮了"，写"暖白光，不偏黄" |
| 听觉 | 声音的节奏、远近、质感——不写"有鼾声"，写"呼气拖长，吸气短到几乎听不到" |
| 嗅觉 | 集中投放在回忆核心场景（美容院=护肤品+烫发药水+洗甲水），成为触发记忆的钥匙 |
| 触觉 | 温度、质地、重量——墙的冷、台阶的光滑、手机的重量 |
| 身体感 | 脖子僵、脚发麻、脸疼——具体的不适比"他很累"有效十倍 |

---

## 四、叙述视角

第三人称有限视角。每章固定一个主视角（杜曦宇或沈思言），叙述只能贴近此人的感知。偶尔插入客观描述（如审讯室环境）制造间离效果。

**禁止**：上帝视角、命运预告、"他不知道的是……""两个人都不知这是最后一面"。

---

## 五、对话风格

无副词标签。只用"说""问"，能不用就不用。情绪通过对话内容和上下文动作传达。对话简短、真实、留白多，经常不完整或答非所问，暗示隔阂和抗拒。

**杜曦宇**：在金主面前逢迎但不卑微，有设计感，有"我跟你是在交易"的暗流。在沈思言面前设计感逐渐失效，偶尔出现裂缝。知道怎么让人舒服——不是天赋，是四年训练的技术。

**沈思言**：精确、简洁、不浪费字。情绪激动时更慢更平。不说"我觉得"，说事实和判断。

> "喝吗？"陈哥问。
> "可以。"
> 陈哥倒了一杯，递给他。
> 杜曦宇接过杯子，喝了一口。
> 酒是凉的，有一点甜，有一点苦。

---

## 六、情感写法

全文避免直接使用"爱""爱情""爱上了"。情感通过五个通道呈现：

1. **动作**：手指停在确认键上。手放在对方胸口数心跳。
2. **选择**：没说"我需要你"，说"你在哪"。
3. **后果**：走后坐了很久。没有哭。只是安静。
4. **身体**：食量少了。呼吸比以前更浅。
5. **留白**：最重的感情不写出来。

**一句式情感确认**：长篇冷静叙述后，关键节点允许一句直白的话。不是喊出来，是针扎。一章最多一次。

**"伪"感**：甜蜜场景同时写表面甜和底下腐烂（身体疲惫、手段痕迹、结构性不安）。读者应在甜蜜中感到不安——"太甜了，不对劲"。

---

## 七、场景切换

硬切。场景之间不用过渡句，空行即切换。

**禁止**："之后他去了……""半小时后……""第二天清晨""三天后"。

**×××× 回忆分隔符**（作者独有技法）：前后各空一行。一章内不超过5个。带有日记/草稿质感，暗示回忆是自动涌上来的。不需要"他想起了……"引导。

回忆与现实的交替：现在时线索（看守所的黑暗、鼾声、脚步声）在回忆段落间不断出现，形成对位节奏。用"拒绝式收束"切回现在时。

---

## 八、作者独有技法

**拒绝式收束**：短句切断回忆流。"再往下，他不想再去想了。"

**品牌直写**：真实品牌名替代描写——希尔顿、巴黎世家、江诗丹顿、特斯拉。品牌携带阶层信息，比"高级酒店"更锋利。直播平台用化名（抖海=抖音）。

**精确数字**：8800低消、49块5余额、150块私人飞机。传递角色的"计算"思维——杜曦宇以算钱的方式看世界。

**音乐嵌入**：通过歌词传递情感基调，一章最多一次。

**嗅觉集中投放**：只在回忆核心场景集中使用。

**冷静比喻**：使用"像……"结构，一章不超过3个。事实本身的重量通常够了。

---

## 九、核心意象

| 意象 | 写法 |
|------|------|
| 凌晨三点 | 安静、少对话、多环境。城市沉睡后的另一个世界。 |
| 包子 | 永远是热的。就是包子。热的是包子，也是两个人还在的证明。 |
| 妆 | 动词不是名词。关注"遮"的动作。 |
| 浴室地板 | 不写冰冷，写"坐在上面"的动作本身。 |
| 看守所 | 灰色、中性、不浪漫化。 |
| 海 | 中性。不评判，只是在那里。 |
| ×××× | 回忆分隔符。 |

---

## 十、特色表达（本作独有）

贯穿全文的语言密码：

- **画圈**：母亲做美容的动作，象征束缚和循环。杜曦宇童年记忆核心意象。
- **四，四，四**：沈思言呼吸控制节奏（吸气四秒，屏息四秒，呼气四秒）。象征自我控制和压抑。
- **可是**：连接"肯定前半句"和"否定后半句"，体现关系矛盾。"妈妈爱你。可是你得……"
- **没有……没有……**：并列否定，表达匮乏和空洞。
- **厕所在左边**：黑暗中微弱的善意，联结的开始。最轻的话，最重的意义。
- **你还可以更好**：父亲的典型话语。以"鼓励"形式出现的否定。
- **好了，没有话了**：对话结束标志，关系疏离。
- **不知道**：面对复杂处境的最终回答。无力、迷失。不是推脱，是真实的空白。
- **像在看一件商品**：物化与审视。被打量、评估、消费的身体感受。
- **像在接受审视**：被物化的目光。与上一条构成镜像。

---

## 十一、每章节奏与字数

1. **开头**：承接上章钩子（简短，不重复）
2. **前段**：迅速给出本章问题/事件
3. **中段**：推进冲突（回忆章=回忆+现在时交替；甜蜜章=表面甜→裂缝→裂缝扩大）
4. **后段**：兑现小结果
5. **结尾**：新钩子（危机/异常/未说出口的话/消息）

每章最少3500字。低于3000必然缺少感官锚点或节奏变化。

---

## 十二、必要描写与场景模板

短句是节奏手段，不是偷懒借口。最少≠不足。

### 必须充分展开（200-400字）

| 场景类型 | 展开要求 |
|----------|----------|
| 关键转折点 | 坐下→思考→计算→站起。不能"他决定忍耐"一句话概括。 |
| 人物首次出场 | 外貌、特征、穿着、环境位置、第一个动作、光线气味。 |
| 核心冲突 | 冲突的具体内容，不能只写"发生了冲突"。 |
| 情感关键节点 | 完整流程（约炮主权证明：打开软件→选择→见面→做完→离开→拉黑）。 |
| 感官密集场景 | 至少5种感官。瓷砖的冷、水滴声、镜子模糊、身体重量、空气湿度。 |
| 回忆核心场景 | 环境、气味、光线、声音完整呈现。 |

### 可以简短

过渡性动作（吃饭、走路）、日常重复、情绪延续、节奏断点。

### 检验三问

读者能否进入场景？能否理解转折？能否感受情绪？任一答"不能"→描写不足。

---

## 十三、写作示例

**推荐：**
> 他走进公寓。客厅很大。窗外的夜景很亮。陈哥坐在对面，眼神里有东西。
>
> 他在搜索栏里输入关键词，点开第一个结果，记下电话，打过去。打完一个，流利地挂了，再打下一个。

——动作驱动。情绪通过节奏传达。不替读者感受。

**避免：**
> 他感到非常难堪和痛苦，因为他知道母亲又在用他炫耀了。
> 他熟练地拨打着电话号码，心中却充满了空虚和迷茫，不知道自己的人生意义在哪里。

——直接告诉读者情绪和"意义"，剥夺感受空间。

- [ ] 删除所有"甜蜜"台词，底下有腐烂？
- [ ] 主角是"用强防御的烂人"而非真强者？
- [ ] 读者能隐约感到"这条路通往悬崖"？
- [ ] 情感通过动作/选择/后果/身体/留白呈现（而非喊出来）？
- [ ] 结尾有钩子？
- [ ] 字数≥3500？
- [ ] 关键转折写出完整过程？
- [ ] 人物首次出场充分展开？
- [ ] 没有一句话概括复杂情节？

- [ ] 对话无副词标签？
