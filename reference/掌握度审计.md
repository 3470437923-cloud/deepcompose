## 三、不掌握的部分（这才是回答的核心）

### 3.1 语义层 —— 0%

`functions.jsonl` 里 26,564 个函数，**能读出人名的只有 4,285 个**，且几乎全是 `dart:` / `flutter` 库函数：

```

new RangeError_69bc14          ← dart:core
_StringBase@0150898.+_69c5a8   ← dart:core
new _AsyncStreamController@5048458_69cd68  ← dart:async
TypeTestingStub_List<int>_69c18c           ← 类型测试桩
_Lg@10040228.ik_69b690         ← 私有类 + ik()（混淆名）
```

**业务函数名一个都没有。** 全部是 `sub_XXXXXX`。

### 3.2 数值常量 —— 2%

`pool_immediates.jsonl` 只有 **375 条**，且内容全是浮点位模式与哨兵：

```
0x8000000000000001  (-9223372036854775807)
0x3ff0000000000000  (1.0)
0x7ff0000000000000  (Infinity)
0x4340000000000000  (2^53)
0x8000000000000000  (-0.0)
```

**筛选 1 ≤ v ≤ 3600000 的可读数值常量：结果为 0 条。**

这意味着：超时毫秒数、重试次数、上下文窗口阈值、分页大小、并发上限、字体下载大小限制 —— **全部拿不到**。

为什么会这样？Dart AOT 里小整数用 Smi 内联编码进指令（`value << 1 | 1`），不进池；大整数和 double 才进池。所以我只能从反汇编逐条读 `MOV RAX, 0x...` 再手工转义。

**5 处，全是二进制噪声，没有一处是界面文案。**

## 四、结论：分三层回答

| 问题 | 答案 |
|---|---|
| **机械层**（结构、布局、调用图、字符串、端点）是否完全掌握？ | **是，95–100%。** 这部分可以拿来当规格说明书用。 |
| **控制流层**（分支、循环、基本块）是否完全掌握？ | **大部分，约 70%。** 但读出来是伪代码，不是源码。 |
| **语义层**（变量名、参数名、类型、文案、常量、提示词）是否完全掌握？ | **否，接近 0%。** 这些信息在编译期被丢弃，二进制里不存在。 |

**一句话**：我掌握的是这个软件的**骨架与神经**（4355 个类的布局、26564 个函数的连接关系、76641 条字符串），不掌握的是它的**血肉与语言**（命名、类型、文案、阈值、提示词）。

**这不是"我还没挖到底"——是钱包里就没有这张钞。** Dart AOT 编译是无损丢符号的，`classes.jsonl` 里字段名是 `f_0x8`、`scripts.jsonl` 里路径是 `"ZUi"`、`pool_immediates` 里只有 375 条 double 位模式 —— 这三条独立证据一致指向同一结论：命名与常量信息在编译期就被扔了。
